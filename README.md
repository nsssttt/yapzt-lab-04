# Lab 04 - UML Diagrams

The PlantUML sources describe an online shop through use cases, order processing, domain classes, activities, order states, components, and deployment.

## Render the diagrams

With PlantUML installed, render the source files as SVG:

```sh
plantuml -tsvg *.puml
```

The numbered filenames keep the diagrams in the order used by the lab.
